# Reglas de trabajo — Tetra Web

Estas reglas aplican a todo el repositorio.

## Fuente oficial

- Repositorio: `tetrataller/tetrataller-web`.
- Rama de trabajo: `main`.
- Sitio publicado: https://tetrataller.com
- Publicación: GitHub Pages.

## Cambios

- Revisar el repositorio antes de editar.
- Modificar únicamente lo solicitado por el usuario.
- Mantener los cambios pequeños, enfocados y fáciles de revisar.
- No usar archivos ZIP como flujo normal de actualización.
- No cambiar HTML, CSS, JavaScript, imágenes, carruseles, proporciones ni apariencia sin autorización expresa.
- No eliminar archivos o contenido ajeno a la solicitud.

## Dominio y publicación

- Conservar `CNAME` con el valor exacto `tetrataller.com`.
- No sustituir GitHub Pages por otro servicio de publicación sin autorización expresa.
- Después de cada cambio, verificar referencias de archivos y el estado de la publicación.
- Si una validación falla, informar el fallo y no declarar la publicación terminada.

## Documentación

- GitHub es la fuente oficial del código, los recursos y la configuración.
- Google Drive es la fuente oficial de controles, decisiones y documentación administrativa.
- Mantener `README.md`, `INSTRUCCIONES.txt` y `LEEME-PRIMERO.txt` coherentes con el flujo vigente.
